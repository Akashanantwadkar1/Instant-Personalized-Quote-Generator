# AI Personal Insurance Advisor

An AI-powered insurance advisor that generates instant, personalized insurance quotes using machine learning and rule-based logic.  
It automates risk analysis, premium calculation, and customer data storage without human intervention.

## Features
- Personalized insurance quote generation
- Machine learning–based risk assessment
- Automated premium calculation
- CSV-based customer data storage
- Clean web interface using Flask

## Tech Stack
- Python
- Flask
- Pandas, NumPy
- Scikit-learn
- HTML, CSS

## How to Run
```bash
pip install -r requirements.txt
python app.py

Use Case

Provides instant, personalized insurance quotes without human intervention, improving customer experience and conversion rates.
